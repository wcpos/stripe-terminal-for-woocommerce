**Stripe Terminal for WooCommerce 2.0.1 is a fix release for 2.0.0. It still requires WooCommerce POS Pro 2.0.0 or newer.**

## What changes

- Updating from 2.0.0-beta1 by uploading the plugin zip and choosing **Replace current with uploaded** no longer stops with a fatal error (`Call to undefined method ... Settings::get_wcpos_connections()`). The same protection covers later updates done this way. The new files arrive while the old version is still running, so for that one page load Stripe Terminal is left off the payment methods and a line is written to the WooCommerce log. From the next page load it works as normal.

## What you need to do

- Nothing. Update as usual.
